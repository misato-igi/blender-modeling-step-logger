# Blender操作記録アドオン（卒業研究用）

卒業研究「Blenderにおける3Dモデリング手法の効率比較 ― 取手付きコップの制作を事例として ―」で使用する記録ツール。

- 対応：Blender 4.5 LTS
- 記録内容：制作時間、操作ステップ数（モデリング操作＋数値変更）、取り消し回数、作業部分（本体／取手／つなぎ・全体）ごとの時間と操作ステップ数、面数、部品の数、穴の数、高さ、直径
- 本実験で使用する版：v1.2
- 作成：仕様の決定と動作確認は筆者、プログラムの作成は生成AI「Claude」（Claude Code）
