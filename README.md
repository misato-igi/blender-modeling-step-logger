# モデリング操作記録 (Modeling Step Logger)

Blender の操作を「形を変える・面を増やす・滑らかにする・その他」の4つに分けて、時間と回数を記録し、グラフで比べられるようにするアドオンです。卒業研究（取手付きコップを3つの手法で作ったときの比較）のために作りました。

## できること
- 操作を4つに分けて、時間と回数を自動で記録する
- 作業の部分（本体・取手・つなぎ・全体）を切り替えて記録する
- 取り消し回数、完成したときの面の数・高さ・直径・部品の数を記録する
- 記録を「まとめ.csv」と「操作ログ」に書き出す（まとめ.csv の「グラフに使う」を × にするとグラフから外れる）
- 「グラフを見る」ボタンで、ブラウザにグラフを表示する（日本語／English 切り替え）

## ファイル
- modeling_step_logger.py：Blender のアドオン
- グラフビューア.html：Blender がなくても開けるグラフ画面。「操作記録」フォルダを読み込んで使う

## 使い方
1. Blender（4.2 以降）の「編集」→「プリファレンス」→「アドオン」→ 右上の ∨ →「ディスクからインストール」で modeling_step_logger.py を選ぶ
2. 3D ビューポートのサイドバー（N キー）の「操作記録」タブで、制作者・手法・試行番号を入れて「記録開始」
3. 作り終わったら「記録終了」→「グラフを見る」

## 時間の数え方
1つの操作の時間は「操作を始めた時刻から、その操作の数字を最後に直した時刻まで」です。「その他」の時間は、制作時間から3種類の時間を引いた残り（選択・視点・考えている時間など）です。
